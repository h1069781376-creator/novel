# Female-Dominant ML Database
## 女尊男主人设数据库（Vol.1）

Version 1.0

---

> **女频最大的误区。**
>
> **不是不会写男主。**
>
> **而是所有男主都像同一个人。**

近几年大量女频男主可以总结为：

```
高冷

腹黑

有钱

强大

占有欲

只爱女主
```

换个名字。

就是另一个男主。

AFNL认为：

真正让读者上头的男主。

一定有：

**自己的生活方式。**

而不是：

围绕女主旋转。

---

# 第一章｜AFNL 男主设计公式

一个优秀男主。

必须至少拥有六个维度。

```
职业身份

+

性格底色

+

行为习惯

+

情绪表达

+

成长创伤

+

爱情语言
```

缺任何一个。

人物都会变薄。

# 第二章｜M001 男妈妈型（★★★★★）

关键词：

照顾欲。

稳定。

生活感。

---

## 核心特征

会做饭。

会收纳。

会养花。

会照顾动物。

情绪稳定。

很少发火。

擅长倾听。

不会控制别人。

---

## 最大魅力

不是照顾。

而是：

**让人安心。**

例如：

她凌晨回来。

他说：

```
锅里还有汤。

热一下就能喝。
```

不是：

```
为什么回来这么晚？
```

---

## 隐藏弱点

不会麻烦别人。

总说：

```
我没事。
```

其实。

最不会照顾的人。

是自己。

---

## 女主负责成长

教会他说：

```
你也可以依赖别人。
```

---

```

会说：

```
今天回来的路。

```

其实。

一点都不顺路。

---

## 弱点

情绪表达障碍。

不知道怎么示弱。

# 第十一章｜M010 自卑大奶男妈妈（AFNL推荐★★★★★）

> 这是近年来最容易爆的细分人设之一。

不是因为：

身材。

而是：

心理。

---

## 外在

身材丰满。

高个子。

肩宽。

腰细。

皮肤白。

看起来。

很有安全感。

---

## 内在

从小因为身材。

被调侃。

一直觉得：

自己不好看。

不够男性化。

---

别人夸：

腹肌。

胸肌。

他都会尴尬。

别人看他。

他会下意识整理衣服。

---

## 女主第一次说

```

```

他说：

```
……真的吗？
```

这是第一次。

有人不是在开玩笑。

女主靠在他怀里。

睡着了。

```

```

都借你。
```

---

不是身材。

而是：

终于有人喜欢。

他曾经最自卑的地方。
