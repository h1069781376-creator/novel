# Signature Scene Database
## 女性向小说名场面数据库（Vol.1）

Version 1.0

---

> **真正封神的，不是剧情。**
>
> **而是一个很多年后，读者还能记得的瞬间。**

很多作者误以为：

名场面 = 大场面。

其实不是。

真正的名场面。

通常发生在：

一个很普通的下午。

一个很普通的人。

做了一件：

只有他会做的事情。

AFNL 将名场面拆解为：

```
人物性格

×

关系阶段

×

行为

×

情绪兑现

=

名场面
```

不是复制桥段。

而是理解设计逻辑。

---

# 第一章｜"我一直记得"型

关键词：

长期记忆。

兑现承诺。

---

## Scene 001

很多年前。

她随口说：

> "我小时候最喜欢吃山楂糖。"

很多年后。

他们一起逛集市。

她已经忘了。

他停下脚步。

买了一包。

递过去。

什么都没解释。

---

为什么有效？

不是山楂糖。

而是：

他一直记得。

---

## Scene 002

第一次见面。

她说：

```
我以后一定要有一个带院子的家。
```

故事最后。

他们搬家。

院子里。

已经种好了她喜欢的花。

---

重点：

不是房子。

是：

未来里一直有她。

# 第九章｜名场面设计公式

所有名场面。

几乎都满足：

```
前期铺垫

+

人物习惯

+

关系推进

+

情绪兑现

+

一句对白

=

名场面
```

例如：

第一章。

他说：

```
以后别忘记带伞。
```

第十五章。

下暴雨。

她没带伞。

他来了。

读者不会感动。

第二十五章。

又下雨。

她还是没带伞。

他没来。

门口放着一把伞。

读者会记住。

因为。

这已经成为：

他的习惯。

# 第十章｜AFNL 名场面禁区

不要刻意制造：

- 人工偶遇
- 平地摔
- 接吻摔
- 狗血误会
- 霸道强吻
- 英雄救美重复使用
- 过度肢体接触
- 强行煽情
- 连续告白
- 连续哭戏

真正的名场面。

一定来自：

人物。

而不是套路。

---

# AFNL 创作法则 No.010

> 名场面不是一段剧情。

> 是很多铺垫之后。

> 人物终于做出了那个：

> **只有他才会做的选择。**

End.
