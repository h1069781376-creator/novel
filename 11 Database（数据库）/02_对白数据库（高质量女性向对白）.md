# Dialogue Database
## 高质量女性向对白数据库（Vol.1）

Version 1.0

---

> 好的对白，不负责解释剧情。
>
> 好的对白，只负责暴露人物。

读者不会因为一句：

> "我爱你。"

喜欢一个角色。

但是会因为一句：

> "今天是不是没人夸你？"

记住他。

---

# 第一章｜对白三原则

## 原则一：人物说话，不是作者说话

错误：

```
"人生总要经历挫折。"

"爱情需要信任。"

"做人应该勇敢。"
```

这是作者。

不是人物。

人物永远只说：

自己会说的话。

---

## 原则二：对白不能解释剧情

错误：

```
"因为你小时候被父母忽视，所以你才这样。"
```

正确：

```
"你是不是……又准备一个人扛？"
```

---

## 原则三：一句对白只能完成一件事

不要：

```
解释剧情

+

表达感情

+

推动剧情

+

输出价值观
```

一句话。

一个目的。

---

# 第二章｜真正温柔的人怎么说话

错误：

```
"别难过。"

"没关系。"

"都会过去。"
```

正确：

```
"今天先不用坚强。"

——

"饭吃了吗？"

——

"要不要先睡一会？"

——

"我在。"

——

"慢慢来。"
```

真正温柔的人。

很少讲大道理。

# 第三章｜真正成熟的人怎么安慰人

错误：

```
"你已经很棒了。"

"不要想太多。"

"加油。"
```

正确：

```
"今天发生什么了？"

——

"想说的话。

我听着。"

——

"现在最难受的是哪件事？"

——

"我们先解决眼前这个。"

——

"剩下的。

以后再说。"
```

成熟的人。

先理解。

再安慰。

# 第四章｜高情商对白

不要：

```
"你怎么哭了？"
```

改成：

```
"今天一定很辛苦吧。"
```

---

不要：

```
"你是不是生气了？"
```

改成：

```
"是不是我哪里做得不好？"
```

---

不要：

```
"你误会我了。"
```

改成：

```
"我可以解释。"

"但如果你现在不想听。

也没关系。"
```

---

不要：

```
"你想多了。"
```

改成：

```
"我没想到。

会让你这样难受。"
```

# 第十章｜吵架对白

真正好的吵架。

没有攻击。

只有表达。

例如：

错误：

```
"你根本不在乎我！"
```

正确：

```
"我只是希望。

你也能偶尔依赖我。"
```

---

错误：

```
"你怎么总这样！"
```

正确：

```
"我不知道怎么靠近你。"
```

---

错误：

```
"算了。"
```

正确：

```
"我现在有点难过。

等我整理好。

再来找你。"
```

---

# 第十一章｜沉默对白

很多时候。

沉默也是对白。

例如：

```
"……"

"嗯。"

"好。"

"知道了。"

"我在。"
```

关键不是字数。

而是：

前后的动作。

---

# 第十二章｜对白节奏

不要：

一个人说十句话。

另一个人一句没有。

优秀对白比例：

```
A一句

↓

B一句

↓

动作

↓

环境

↓

A一句

↓

沉默

↓

B一句
```

让对白：

像呼吸。

---

# 第十三章｜对白禁用词（高频AI表达）

减少使用：

```
你放心。

相信我。

我永远不会。

以后有我。

一切都会好的。

命中注定。

非你不可。

此生不负。

我养你。

我的命都是你的。

你只能是我的。
```

这些不是不能写。

而是：

说出来之前。

先让人物做到。

# 第十四章｜对白检查清单

完成一段对白后。

检查：

□ 去掉名字，还能认出是谁说的吗？

□ 每个人说话节奏是否不同？

□ 有没有一句话可以删掉？

□ 有没有人在解释自己？

□ 有没有作者借角色说教？

□ 有没有一句值得记住的话？

如果全部通过。

对白完成。
