# Emotional Value Database
## 情绪价值数据库（Vol.1）

Version 1.0

---

> **女性向小说最值钱的东西，不是爱情。**
>
> **是情绪价值。**

很多作者理解的情绪价值：

```
夸她。

宠她。

照顾她。

送礼物。
```

这些都只是表面。

真正的情绪价值，是：

> **一个人的存在，让另一个人更喜欢自己。**

爱情只是载体。

成长才是目的。

---

# 第一章｜什么是真正的情绪价值

请记住一句话。

> **真正爱你的人，不会让你越来越自卑。**

而是：

越来越自在。

越来越放松。

越来越敢做自己。

所以。

情绪价值不是：

"我帮你。"

而是：

"你和我在一起的时候，不需要伪装。"

---

# 第二章｜情绪价值九层模型

AFNL 将情绪价值拆成九层。

每一层都可以成为：

剧情。

对白。

人物魅力。

---

## Level 1

存在感。

```
有人发现你来了。
```

例如：

她刚推开门。

他说：

```
"今天晚了十分钟。"
```

不是责备。

而是：

他注意到了。

---

## Level 2

记忆感。

```
有人记住了你。
```

例如：

半年前。

她说：

喜欢桂花。

秋天。

他送来一小袋桂花糖。

没有解释。

---

## Level 3

理解感。

```
有人真正理解你。
```

例如：

别人说：

```
你怎么又加班？
```

他说：

```
你不是喜欢加班。

你是不放心交给别人。
```

---

## Level 4

安全感。

```
有人不会轻易离开。
```

例如：

她说：

```
今天状态不好。
```

他说：

```
没关系。

今天我陪你慢一点。"
```

---

## Level 5

认可感。

```
有人相信你的能力。
```

例如：

所有人反对她负责项目。

他说：

```
我负责结果。

她负责决定。
```

---

## Level 6

尊重感。

```
有人尊重你的边界。
```

例如：

她说：

```
今天想一个人待会。

```

他说：

```
好。

晚饭放门口。
```

没有追问。

没有生气。

---

## Level 7

偏爱感。

```
有人区别对待你。
```

例如：

公司聚餐。

所有人都是统一套餐。

她的是单独点的。

因为。

他知道。

她不能吃辣。

---

## Level 8

归属感。

```
有人把你放进未来。"
```

例如：

他说：

```
以后装修的时候。

厨房做大一点。

你喜欢做甜点。
```

他没有问：

"要不要结婚。"

但未来里。

已经有她。

---

## Level 9

成长感。

```
有人让你成为更好的自己。
```

例如：

以前。

她不敢演讲。

后来。

第一次站上台。

下台以后。

他说：

```
今天比上次多看了观众三次。

很好。
```

他不是夸：

优秀。

而是：

看见成长。

---

# 第三章｜真正的夸奖

不要夸：

```
漂亮。

优秀。

聪明。
```

这些太空。

真正有效的是：

具体。

例如：

不要：

```
今天很好看。
```

写：

```
你今天笑的时候。

眼睛终于没有那么累了。
```

---

不要：

```
你真厉害。
```

写：

```
刚才那么多人。

你还是把事情说清楚了。
```

---

不要：

```
你真温柔。
```

写：

```
刚才那个小朋友哭的时候。

你第一反应是蹲下来。
```

---

# 第四章｜允许失败

真正高质量关系。

一定允许失败。

例如：

考试失败。

他说：

```
今天先吃饭。

成绩。

明天再看。
```

---

创业失败。

他说：

```
店没了。

人还在。

重新开。"
```

---

修仙失败。

他说：

```
这次没突破。

那就下次。"
```

真正的安全感。

来自：

失败以后。

还有人站在身边。

---

# 第五章｜允许情绪

不要急着解决。

先允许。

例如：

她哭。

不要：

```
别哭。
```

写：

```
哭完再说。

我等你。
```

---

她生气。

不要：

```
冷静一点。
```

写：

```
你先说。

我听。"
```

---

她沉默。

不要：

```
你怎么了？
```

写：

```
今天不想讲话。

也可以。"
```

---

# 第六章｜允许脆弱

真正成熟的人。

不会说：

```
你要坚强。
```

而是：

```
今天可以不用坚强。
```

---

不会说：

```
别怕。
```

而是：

```
害怕也没关系。"
```

---

不会说：

```
你一定能做到。
```

而是：

```
做不到。

我也不会走。"
```

---

# 第七章｜共同承担

真正的爱情。

不是：

替对方解决。

而是：

一起面对。

例如：

不要：

```
交给我。
```

写：

```
我们一起想办法。"
```

---

不要：

```
我保护你。
```

写：

```
今天我站前面。

明天换你。"
```

---

# 第八章｜真正的陪伴

陪伴不是：

一直讲话。

真正的陪伴：

允许安静。

例如：

她写方案。

他看书。

一下午。

没人讲话。

却一直在同一个房间。

这就是：

陪伴。

# 第九章｜情绪价值行为库（第一批）

---

### EV001

她忘记自己生日。

他也没提醒。

只是下班时说：

```
今天早点回家。
```

推开门。

朋友已经到了。

---

### EV002

她第一次做饭。

盐放多了。

他说：

```
今天适合配很多饭。"
```

没有一句：

"太咸了。"

---

### EV003

她做演讲。

一直找不到稿子。

他把备用打印稿放在第一排。

一句话没说。

---

### EV004

她发烧。

醒来。

药已经分好。

旁边贴着便签：

```
热了再喝。"
```

---

### EV005

她工作失败。

他说：

```
今天不要总结。

今天先休息。
```

---

### EV006

她第一次直播。

很紧张。

结束以后。

他说：

```
你比昨天勇敢一点。"
```

---

### EV007

她减肥失败。

他说：

```
今天吃火锅。

明天再开始。
```

---

### EV008

她创业赔钱。

他说：

```
赔的是钱。

不是你。
```

---

### EV009

她说：

```
我是不是越来越差了？
```

他说：

```
不是。

只是最近太累。"
```

---

### EV010

她加班回家。

灯亮着。

饭热着。

人睡着了。

桌上留了一张纸。

```
回来叫我。
```

```
发现

+

理解

+

尊重

+

回应

+

陪伴

+

成长

=

真正的情绪价值
```

> 最好的爱情。

> 不是让一个人变得完美。

> 而是让她终于相信：

> **即使不完美，也值得被爱。**

End.
