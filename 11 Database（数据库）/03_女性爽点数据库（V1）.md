# Female Dopamine Database
## 女性爽点数据库（Vol.1）

Version 1.0

---

> **爽点，不是打脸。**
>
> **爽点，是情绪需求被满足。**

很多作者理解错了。

认为女频爽文就是：

```
虐渣

打脸

升级

逆袭

复仇
```

这些只是：

表现形式。

真正让女性读者停不下来的是：

**情绪满足。**

AFNL将女性爽点拆成九大模块。

---

# 第一章｜被坚定选择

> 世界上有很多人。

> 但我还是选择你。

这是女性向最强爽点之一。

不是因为：

女主赢了。

而是：

她被坚定地选择。

---

例如：

所有人都觉得。

联姻对象应该选择公主。

最后。

男主说：

```
"我从来没考虑过别人。"
```

---

例如：

所有人撤退。

只有他留下。

---

例如：

别人都相信流言。

只有他问：

```
"你想告诉我什么？"
```

---

例如：

她输了比赛。

他说：

```
"输了又怎么样？"

"我又不是喜欢冠军。"
```

---

爽点来源：

不是爱情。

是：

确定性。

---

# 第二章｜有人理解自己

真正的理解。

不是：

```
我懂你。
```

而是：

别人看见了。

她一直藏起来的部分。

例如：

所有人都说：

她很坚强。

只有一个人说：

```
"你是不是已经很久没有休息了？"
```

---

例如：

别人夸她优秀。

他说：

```
"一直这么努力。

是不是很累？"
```

---

真正的理解。

一定具体。

---

# 第三章｜终于不用逞强

女性读者非常喜欢这一类剧情。

因为现实中。

很多女性长期承担：

情绪管理者。

照顾者。

协调者。

所以小说里最大的爽点之一就是：

**终于有人替她承担。**

例如：

她准备解释。

男主已经说：

```
"不用解释。"

"我相信你。"
```

---

例如：

她准备自己搬箱子。

男主自然接过去。

没有一句：

"你搬不动。"

只是：

```
"太重。"

"一起。"
```

重点：

不是帮助。

而是：

尊重。

---

# 第四章｜女主终于不用证明自己

很多小说。

一直让女主：

证明能力。

证明清白。

证明价值。

AFNL认为。

真正高级的爽点。

来自：

不用证明。

例如：

有人质疑她。

男主没有解释。

直接把合同递过去。

```
"签字的人是我。"

"有问题找我。"
```

或者：

所有人等着她解释。

她一句没说。

真正了解她的人。

已经站出来。

---

这种爽。

叫：

信任爽。

---

# 第五章｜成长被看见

努力。

终于被发现。

不是：

得奖。

而是：

有人记得。

例如：

女主刚创业的时候。

店里一个客人都没有。

三年以后。

同一个老人再次出现。

笑着说：

```
"小姑娘。"

"你终于把店开起来了。"
```

---

成长。

终于有人见证。

非常容易触发情绪。

---

# 第六章｜身份反转

不是：

真假千金。

不是：

皇室血统。

真正高级反转。

来自：

认知改变。

例如：

大家都以为。

女主只是一个普通老师。

后来发现。

她一直匿名资助山区学校。

重点不是：

有钱。

而是：

一直在做。

---

# 第七章｜尊重她的选择

不要写：

```
为了你好。
```

写：

```
"我不同意。"

"但如果这是你的决定。"

"我陪你。"
```

---

真正的尊重。

不是放手。

是：

陪伴。

---

# 第八章｜共同成长

爱情最爽的地方。

不是：

男主改变女主。

也不是：

女主拯救男主。

而是：

他们都变好了。

例如：

以前。

男主不会表达。

后来。

学会说：

```
"今天辛苦了。"
```

以前。

女主什么都自己扛。

后来。

学会说：

```
"可以帮我一下吗？"
```

这就是：

双成长。

---

# 第九章｜生活感爽点

女性向最大的优势。

是：

生活。

例如：

她加班。

回家。

灯已经亮着。

饭已经做好。

猫跑过来。

有人说：

```
"回来了？"
```

没有反派。

没有高潮。

没有逆袭。

但评论区会刷：

```
太甜了。

好幸福。

想谈恋爱。
```

因为。

这满足的是：

家的幻想。

---

# 第十章｜真正的大女主爽点

不是：

谁都不需要。

而是：

她可以需要别人。

也可以独立完成。

真正的大女主。

不是孤独。

而是：

拥有选择权。

例如：

她能一个人创业。

也能和喜欢的人一起吃早餐。

她能保护别人。

别人也能保护她。

她不会因为恋爱。

失去自己。

也不会因为独立。

拒绝幸福。

```
① 被坚定选择

② 被理解

③ 被尊重

④ 被信任

⑤ 被偏爱
```

几乎覆盖了绝大多数高口碑女性向作品的情绪内核。
