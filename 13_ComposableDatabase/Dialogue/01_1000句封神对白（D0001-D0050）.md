# Signature Dialogue Database
## 1000句封神对白数据库（第一卷）

Version 1.0

---

> **真正让读者截图保存的，不是金句。**
>
> **是人物说出来的话。**

很多作者喜欢写：

```
"我会永远爱你。"

"你是我的全世界。"

"没有你我活不了。"
```

这些不是人物。

是谁都可以说。

AFNL对白原则：

**一句对白，只能属于这一个人物。**

读者看见一句话。

不用名字。

就知道是谁说的。

这才是人物语言。

# 第六章｜对白设计公式

优秀对白满足四个原则：

```
符合身份

+

符合性格

+

符合关系阶段

+

留下余味
```

例如：

一个沉默寡言的剑修。

不会突然长篇告白。

一个年下钓系。

不会一直说大道理。

**对白必须长在人物身上。**

# 第七章｜对白禁区

避免以下高频 AI 式对白：

- "我命都给你。"
- "没有你我活不了。"
- "你是我的全世界。"
- "我发誓永远不会离开。"
- "相信我。"
- "你怎么这么傻。"
- "女人，你成功引起了我的注意。"

这些对白的问题不是老套。

而是：

**任何人物都能说。**

没有人格。
