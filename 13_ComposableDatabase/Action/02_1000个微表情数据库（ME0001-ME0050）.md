# Micro Expression Database
## 1000个微表情数据库（第一卷）

Version 2.0

---

> **真正暴露情绪的，从来不是语言。**
>
> **而是微表情。**

很多 AI 写人物表情时，喜欢使用：

- 微微一笑
- 嘴角上扬
- 脸色一变
- 神情复杂
- 愣了一下
- 瞳孔一缩

这些词本身没有错。

问题在于：

**没有人物差异。**

一个剑修。

一个医生。

一个商人。

一个男妈妈。

不能拥有完全一样的表情习惯。

AFNL 微表情数据库遵循三个原则：

```
人物身份

×

当下情绪

×

身体习惯

=

真实微表情
```

# 第六章｜微表情设计公式

优秀微表情：

```
真实身体反应

+

情绪克制

+

人物习惯

=

可信度
```

例如：

不要写：

> 她害羞了。

改写：

> 她回答得很认真，只是拿杯子的手，悄悄换成了另一只。

不要写：

> 他很开心。

改写：

> 电梯门关上以后，他才发现，自己一直在笑。

# 第七章｜微表情禁区

避免重复使用：

- 瞳孔一缩
- 神情复杂
- 嘴角疯狂上扬
- 微微一愣
- 面色大变
- 呼吸一滞
- 心头一震
- 心漏跳一拍

这些表达已经高度模板化。

优先描写：

- 呼吸节奏
- 手部动作
- 站姿变化
- 视线移动
- 肌肉放松或紧绷
- 声音细微变化

让读者自己推断情绪，而不是直接告诉读者。
