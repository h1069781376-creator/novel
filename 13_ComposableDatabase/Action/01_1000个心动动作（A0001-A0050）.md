# Heartbeat Action Database
## 1000个心动动作数据库（第一卷）

Version 1.0

---

> **真正让读者心动的，从来不是告白。**
>
> **而是动作。**

女性向小说里，动作的作用远远大于对白。

一句：

> 我喜欢你。

远远不如：

> 她睡着以后，他轻轻把滑落的书拿走，再把台灯调暗。

动作不会骗人。

动作代表人物真正的潜意识。

AFNL动作数据库遵循一个原则：

**所有动作，都必须符合人物性格。**

不要为了甜而甜。

# AFNL 动作设计原则

一个真正让人心动的动作，应满足四个条件：

```
自然发生

+

符合人物性格

+

回应对方需求

+

不期待回报
```

动作越小。

情绪越大。
