# Female-Dominant World Building
## 女尊小说世界观设计（AFNL）

Version 1.0

---

> **大多数女尊小说最大的错误。**
>
> **只是把男女身份互换。**

真正优秀的女尊。

不是：

```
男人生孩子

女人当皇帝

男人宅家

女人赚钱
```

这只是：

"男女互换。"

不是：

世界观。

AFNL认为：

**女尊世界，是一套完整的社会运行逻辑。**

---

# 第一章｜女尊世界的底层逻辑

请先回答一个问题。

为什么会形成女尊？

如果回答不了。

整个世界观都会很薄。

AFNL推荐五种形成方式。

---

## 模型一｜武力决定权力（推荐★★★★★）

这个世界。

女性平均灵力。

身体素质。

修炼天赋。

远高于男性。

于是。

女性逐渐成为：

国家统治者。

宗门掌权者。

军队统帅。

这是最容易建立合理性的模式。

---

## 模型二｜血脉继承

只有女性。

能够稳定继承灵根。

王位。

神力。

家族血统。

于是。

女性天然成为：

继承人。

---

## 模型三｜生育价值

世界人口锐减。

女性拥有特殊生育能力。

国家开始重点保护女性。

数百年以后。

社会文化完全改变。

---

## 模型四｜神权

创世神。

历代神明。

全部女性。

于是：

文化。

法律。

信仰。

都围绕女性建立。

---

## 模型五｜历史革命（推荐★★★★★）

几百年前。

女性推翻旧王朝。

建立新制度。

至今仍影响整个社会。

这是最容易写政治剧情的模式。

---

# 第二章｜不要让所有男人都柔弱

这是新人最容易踩的坑。

真正优秀的女尊。

男性。

依旧拥有：

人格。

职业。

理想。

能力。

区别只是：

社会地位。

而不是：

智商下降。

---

错误：

```
所有男人：

哭。

害羞。

等保护。

```

正确：

```
有人是将军。

有人是商人。

有人是神医。

有人是刺客。

有人是谋士。

有人是先生。

有人是乐师。
```

社会位置不同。

人物一样丰富。

---

# 第三章｜男主为什么喜欢女主？

不要：

因为她强。

真正应该设计：

她满足了男主真正缺失的东西。

例如：

男主一直优秀。

却从没人问过：

```
你累吗？
```

女主问了。

---

男主一直漂亮。

所有人只看脸。

女主第一次问：

```
你喜欢做什么？
```

---

男主一直被保护。

女主第一次相信：

```
你可以自己决定。
```

爱情。

来自：

需求。

不是设定。

---

# 第四章｜女性权力如何体现？

不要：

天天上朝。

天天打仗。

真正高级的是：

细节。

例如：

婚书。

由女方准备。

族谱。

记录母系。

孩子。

随母姓。

继承权。

默认长女。

官职。

女性占七成。

这些细节。

比一句：

```
这是女尊世界。
```

更有效。

---

# 第五章｜男性社会规则

真正优秀的世界。

所有人都有规则。

例如：

男子成年后。

可以选择：

入仕。

经商。

从军。

研究机关。

成为医师。

成为乐师。

成为学者。

不是：

只能嫁人。

---

真正自由。

意味着：

人人都有选择。

---

# 第六章｜婚姻制度

推荐：

契约婚姻。

双方都可以解除。

财产独立。

婚前协议。

共同抚养。

这样。

更符合现代女性阅读习惯。

---

# 第七章｜不要复制现实压迫

很多作者喜欢：

把现实女性遭遇。

全部放到男性身上。

例如：

```
裹脚

限制出门

不能读书

不能工作

不能继承

不能表达
```

这种写法。

读者初看新鲜。

后面容易疲劳。

AFNL建议：

**不要复制压迫。**

创造新的制度。

例如：

男子成年后必须参加"礼仪考试"才能入仕。

例如：

名门世家男子也有"择妻季"，类似古代科举与相亲结合。

例如：

高门贵族男性拥有很高文化地位，但婚姻自由受到家族利益影响。

这样世界会更真实。

---

# 第八章｜大女主真正的魅力

大女主不是：

天下无敌。

真正的大女主。

拥有三种力量：

第一：

改变命运。

第二：

改变别人。

第三：

改变时代。

例如：

她不仅成为女帝。

还修改了婚姻法。

例如：

她不仅建立宗门。

还允许男子进入修炼学院。

真正伟大的角色。

一定推动社会。

---

# 第九章｜男妈妈人设（AFNL推荐）

这是近几年女性向最受欢迎的人设之一。

注意。

男妈妈。

不是保姆。

而是：

情绪稳定。

生活能力强。

细心。

成熟。

边界感强。

例如：

会做饭。

会照顾人。

会倾听。

会表达。

会道歉。

会尊重。

但同时：

也有自己的事业。

自己的理想。

自己的原则。

他不是：

围着女主转。

而是：

和女主并肩。

---

# 第十章｜女尊爱情公式

真正优秀的女尊爱情：

```
权力平衡

+

人格平等

+

能力互补

+

共同成长

=

高质量CP
```

不要：

一方永远拯救另一方。

让双方都成为彼此人生的重要力量。

完成设定后。

□ 经济如何运转？

世界观成立。
