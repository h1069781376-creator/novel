# 女性向男主人物设计学（Male Lead Design）

Version：1.0

---

> 女性喜欢的不是一种男人。
>
> 女性喜欢的是一种「关系体验」。

所以。

不要先设计男主。

先设计：

**女主和他在一起以后，会变成什么样的人。**

---

# 第一章｜女性向男主第一原则

男主不是奖励。

男主不是战利品。

男主不是剧情NPC。

男主存在的意义：

不是让女主恋爱。

而是：

让女主成为更自由的人。

如果一段爱情。

让女主越来越小心。

越来越委屈。

越来越没有自己。

那它不是爱情。

---

# 第二章｜真正吸引人的不是完美

下面两个人。

哪个更容易让人记住？

A

```
修为第一

长得最好看

身份最高

最聪明

不会输
```

B

```
修为第一。

不会做饭。

害怕打雷。

喝药要放糖。

总觉得自己不值得别人喜欢。
```

永远是B。

因为：

读者开始想了解他。

不是羡慕他。

---

# 第三章｜女性向人物四层结构

不要做人设。

做人。

任何男主。

都应该拆成四层。

```
第一层

别人眼里的他

↓

第二层

真实的他

↓

第三层

只有女主知道的他

↓

第四层

连他自己都没发现的自己
```

真正的剧情。

发生在：

第二层。

第三层。

第四层。

---

## 示例

别人眼里：

```
宗门第一剑修。

冷漠。

不近人情。
```

真实：

```
社恐。

不知道怎么聊天。
```

只有女主知道：

```
每天偷偷喂猫。

每只都取了名字。
```

连他自己都不知道：

```
其实很害怕孤独。
```

这就是人物厚度。

---

# 第四章｜男主必须拥有自己的生活

如果女主今天消失。

男主会干什么？

回答：

如果只有：

```
找女主。
```

失败。

正确答案应该是：

```
继续处理朝政。

继续经营店铺。

继续修炼。

继续照顾妹妹。

继续治病。

继续生活。
```

然后。

每天都会想她。

爱情不是人生全部。

---

# 第五章｜真正的男妈妈

很多作者理解错了。

男妈妈≠保姆。

真正的男妈妈。

是一种人格。

## Caregiver（照顾者人格）

特点：

```
观察细节。

习惯照顾别人。

容易忽略自己。

表达爱意的方法：

行动。
```

例如：

女主：

"今天不想吃饭。"

错误：

```
快吃。

不吃身体不好。
```

正确：

```
半小时以后。

厨房飘出粥的味道。

他什么都没说。

只是把勺子放在她顺手的位置。
```

---

# 第六章｜大奶男妈妈设计公式

> 不要设计身体。

设计：

身体焦虑。

例如：

错误：

```
胸很大。

身材很好。
```

正确：

```
他总穿宽大的外袍。

夏天也一样。

女主后来才知道。

因为小时候。

所有人都笑他像姑娘。
```

再例如：

```
她第一次抱他。

他说：

"会不会……有点硌？"

她愣了一下。

"哪里？"

"……这里。"

他低头。

耳朵已经红透了。

"别人都说不好看。"

她伸手抱得更紧一点。

"谁说的？"

"我挺喜欢。"
```

真正让人心动的。

不是胸。

是：

有人终于接受了他一直自卑的地方。

---

# 第七章｜犬系

犬系不是：

听话。

而是：

回应。

特点：

```
不会控制女主。

会回应女主。

不会要求。

会等待。

不会猜测。

会询问。
```

例如：

错误：

```
今天不准出去。
```

正确：

```
回来以后。

给我发消息。

让我知道你平安。

好吗？
```

---

# 第八章｜狐狸系

狐狸。

不是绿茶。

而是：

知道自己漂亮。

也知道别人喜欢自己。

但是。

只在女主面前。

收起所有技巧。

例如：

所有人：

都觉得他会撩。

实际上。

女主摸一下头。

他就不会说话了。

---

# 第九章｜清冷系

真正的清冷。

不是：

惜字如金。

而是：

情绪表达很少。

但是。

行为永远诚实。

例如：

他说：

"随便。"

结果。

提前一个小时。

到车站等她。

---

# 第十章｜病弱系

病弱。

不是天天吐血。

真正的病弱。

应该影响生活。

例如：

不能熬夜。

怕冷。

药不能停。

容易累。

但。

不会一直卖惨。

真正打动人的。

不是病。

而是：

他努力生活。

---

# 第十一章｜战损

不要：

受伤。

包扎。

结束。

真正的战损。

会留下痕迹。

例如：

以前：

左手写字。

后来：

只能右手。

以前：

喜欢喝酒。

后来：

胃不好。

以前：

跑得最快。

后来：

雨天会疼。

伤口。

应该改变一个人的生活。

---

# 第十二章｜真正的高光时刻

不要设计：

男主打赢所有人。

设计：

别人做不到的细节。

例如：

女主开会。

一直摸耳环。

他知道。

她紧张。

于是。

把自己的戒指摘下来。

放进她掌心。

什么都没说。

等会议结束。

她才发现。

戒指内侧。

刻着两个字。

```
别怕。
```

---

# 第十三章｜真正的浪漫

浪漫不是：

烟花。

玫瑰。

999朵花。

真正的浪漫：

是长期记住。

例如：

她五年前。

说过一句：

小时候想养一只白猫。

后来。

搬家的第一天。

阳台上。

多了一只猫。

她问：

"什么时候养的？"

他说：

"今天。"

停了一下。

"其实找了三个月。"

---

# 第十四章｜男主成长弧光

男主必须改变。

例如：

开始：

```
觉得：

自己只有有价值。

才值得被爱。
```

后来：

```
发现。

什么都没有的时候。

依然有人爱他。
```

成长。

完成。

---

# AFNL 禁止事项

禁止：

- 用身份代替人格。
- 用标签代替塑造。
- 用外貌代替魅力。
- 用深情代替尊重。
- 用占有代替爱情。
- 用控制代替保护。
- 用牺牲代替成长。
- 用苦难代替深度。

---

# AFNL 总结

真正让读者心动的。

从来不是：

"他有多好。"

而是：

"只有他，会这样爱人。"
