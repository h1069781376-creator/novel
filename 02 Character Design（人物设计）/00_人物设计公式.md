# 人物设计公式（Character Architecture）

Version：1.0

> **一个真正有魅力的人物，不是"设计出来的"，而是"推导出来的"。**

---

# 一、AFNL人物设计公式

```
人物

=

社会身份

+

成长环境

+

核心创伤

+

核心欲望

+

核心恐惧

+

人格底色

+

表达方式

+

爱情模式

+

反差点

+

不可替代性

+

成长弧光
```

如果缺少其中任何一项。

人物都会变成：

"标签人。"

---

# 二、第一层：社会身份（Identity）

身份决定：

别人怎么看他。

不是：

他是谁。

例如：

```
女帝

医生

程序员

魔尊

掌门

皇子

演员

律师

首辅

商人
```

身份只能决定：

社会角色。

绝不能决定：

人物性格。

例如：

医生。

可以：

爱哭。

可以：

暴躁。

可以：

社恐。

可以：

嘴碎。

不要因为职业。

限制人物。

---

# 三、第二层：成长环境（Background）

成长环境。

决定人物：

处理世界的方法。

例如：

独生女。

容易：

习惯独自解决问题。

家里有很多弟弟妹妹。

容易：

先照顾别人。

从小被否定。

容易：

过度证明自己。

从小被溺爱。

容易：

害怕失败。

成长环境。

不会决定：

命运。

只会影响：

选择。

---

# 四、第三层：核心创伤（Core Wound）

所有主要角色。

必须有一个：

不会轻易痊愈的伤口。

不是为了虐。

而是：

解释人物。

例如：

小时候。

没人相信他说的话。

所以。

成年以后。

别人一句：

"我相信你。"

就会击中他。

例如：

小时候。

一直被夸懂事。

所以。

成年以后。

不会表达需求。

例如：

小时候。

总被比较。

所以。

特别害怕：

自己不够好。

创伤。

不是剧情。

而是人物系统。

---

# 五、第四层：核心欲望（Core Desire）

不要写：

```
想变强。
```

太空。

太大。

真正的欲望。

必须具体。

例如：

```
想拥有自己的家。

想重新开一家面馆。

想治好母亲。

想让别人记住自己的名字。

想活下来。

想证明自己值得被爱。

想离开那个地方。
```

欲望越具体。

人物越真实。

---

# 六、第五层：核心恐惧（Core Fear）

恐惧。

永远对应欲望。

例如：

```
欲望：

拥有家。

↓

恐惧：

再次失去。
```

例如：

```
欲望：

相信别人。

↓

恐惧：

再次被骗。
```

不要设计：

怕死。

怕黑。

怕鬼。

这种表层恐惧。

真正推动剧情的是：

情绪恐惧。

例如：

```
害怕被抛弃。

害怕没价值。

害怕重复父母的人生。

害怕成为自己讨厌的人。

害怕依赖别人。
```

---

# 七、第六层：人格底色（Personality Core）

人格。

只能有一个核心。

例如：

```
责任感。

自由。

控制。

善良。

理性。

浪漫。

好奇。

野心。

秩序。

共情。
```

后续所有行为。

都应该围绕这一点展开。

例如：

责任感。

会导致：

主动承担。

容易愧疚。

不会推卸。

例如：

自由。

会导致：

讨厌控制。

害怕束缚。

拒绝被定义。

---

# 八、第七层：表达方式（Expression）

不要设计：

"高冷。"

那不是表达。

真正应该设计：

人物如何表达情绪。

例如：

开心。

有人：

会笑。

有人：

会做饭。

有人：

会买东西。

有人：

会一直讲话。

有人：

一句话都不说。

例如：

生气。

有人：

沉默。

有人：

阴阳怪气。

有人：

开始收拾房间。

有人：

疯狂工作。

表达方式。

才决定：

对白。

动作。

氛围。

---

# 九、第八层：爱情模式（Love Pattern）

所有角色。

必须回答：

他如何爱人？

例如：

照顾型。

行动型。

陪伴型。

夸奖型。

分享型。

成长型。

牺牲型。

不要混乱。

例如：

男妈妈。

一般属于：

行动型。

陪伴型。

照顾型。

不是：

天天说情话。

---

# 十、第九层：反差（Contrast）

反差。

必须来自：

统一人格。

而不是：

随机设定。

例如：

```
外表：

冷。

↓

实际：

很容易心软。
```

为什么？

因为：

他害怕失去。

所以：

故意保持距离。

这就是：

逻辑。

不要：

```
高冷。

↓

突然话很多。
```

没有原因。

就是OOC。

---

# 十一、第十层：不可替代性（Uniqueness）

回答：

如果把这个角色删掉。

还能换成别人吗？

如果：

可以。

说明：

失败。

例如：

男妈妈。

真正不可替代的。

不是：

会做饭。

而是：

他照顾人的方式。

别人做不到。

例如：

女主失眠。

别人：

安慰。

他说：

"不用睡。"

"今晚我陪你醒着。"

这就是：

角色独有行为。

---

# 十二、第十一层：成长弧光（Character Arc）

人物。

必须改变。

否则。

故事没有意义。

成长公式：

```
错误认知

↓

经历事件

↓

认知动摇

↓

重新选择

↓

成长完成
```

例如：

他一直认为：

"只有有价值的人才值得被爱。"

后来。

有人在他最狼狈的时候。

依然留下。

于是。

他开始相信：

人。

不是因为优秀。

才值得被爱。

这才叫成长。

---

# 十三、AFNL人物检查表

每个主要角色。

完成后。

检查：

□ 有没有具体欲望？

□ 有没有具体恐惧？

□ 有没有成长环境？

□ 有没有核心创伤？

□ 有没有固定表达方式？

□ 有没有爱情模式？

□ 有没有反差？

□ 有没有不可替代行为？

□ 有没有完整成长弧光？

□ 删除身份后，这个人是否依然成立？

全部通过。

人物完成。

---

# AFNL 人物原则

不要创造一个完美的人。

创造一个：

今天读者会想认识。

明天会想保护。

故事结束以后。

还会想念的人。

End.
