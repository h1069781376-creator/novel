# AFNL Novel Engine
## AI Smell Checker（AI味检测器）

Version 1.0

---

> **AI味，不是AI写的。**
>
> **AI味，是模式重复。**

很多作者认为：

AI味来自：

```
文笔不好。
```

其实完全不是。

真正的 AI 味来自：

> **重复。**

重复的句式。

重复的情绪。

重复的节奏。

重复的词汇。

重复的人物。

重复的剧情。

读者的大脑会迅速识别：

> "这个人在套模板。"

所以。

Novel Engine 不检测：

是不是 AI 写的。

而检测：

**重复模式。**

# 第十三章｜Rewrite Rule

不是：

删词。

而是：

改结构。

例如：

原文：

```
她轻轻点了点头。
```

改：

```
她没有立刻回答。

几秒后。

才点头。
```

情绪。

更真实。

---

原文：

```
他深情地望着她。
```

改：

```
她说话的时候。

他一直没有移开视线。
```

不要解释。

写行为。
