# 为什么 AI 小说越来越像 AI？

很多人认为：

是因为文笔。

其实不是。

真正的问题是：

**一致性（Consistency）。**

读者会发现：

第一章：

```
男主不会做饭。
```

第十五章：

```
男主做了一桌菜。
```

第一章：

```
女主社恐。
```

第十章：

```
女主突然成为演讲达人。
```

AI不会觉得有问题。

因为它生成的是：

**下一段文字。**

不是：

**整本小说。**

所以。

Novel Engine 必须拥有：

Consistency Checker。

> 小说不是一次生成。

> 小说是：

> **生成。**

> **检查。**

> **再检查。**
